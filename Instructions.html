🚀 Quick Start Guide

This guide will walk you through using ClashSockify on Windows with the mihomo core.

Step 1: Generate Configuration File

Open the ClashSockify tool in your browser and paste your Clash subscription content. After setting your authentication details and port, click "Generate Configuration" and download the resulting `socks.yaml` file.

Step 2: Prepare the Files

Create a new folder. Place all the files from this GitHub project into it.

Next, download the mihomo core for Windows. Rename the executable file to `mihomo-windows-amd64-v1.exe` and place it in the same folder.

Finally, move the `socks.yaml` file you generated in Step 1 into this same folder.

Step 3: Run the Service

With all the files in the same directory, right-click the `start_mihomo.ps1` file and select "Run with PowerShell" to start the service.
