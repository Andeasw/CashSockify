🚀 Quick Start Guide

This guide will walk you through using ClashSockify on Windows with the mihomo core.

Step 1: Generate Configuration File

Open the ClashSockify tool in your browser and paste your Clash subscription content. After setting your authentication details and port, click "Generate Configuration" and download the resulting `socks.yaml` file.

Step 2: Configure the Startup Script

Place the downloaded `socks.yaml` file in the same folder as your `mihomo.exe` core program (e.g., D:\Mihomo\). Open the `start_mihomo.ps1` script with a text editor to modify the path configurations at the top.

Please ensure the following paths exactly match your actual file locations: 

# --- User Configuration Area ---

# 1. Full path to the Mihomo core executable
$MihomoPath = "D:\Mihomo\mihomo.exe"

# 2. Full path to the configuration file generated by ClashSockify
$ConfigFile = "D:\Mihomo\socks.yaml"

# 3. Directory where log files will be stored (will be created automatically)
$LogDir     = "D:\Mihomo\logs"

# --- End of Configuration ---

Step 3: Run the Service

Save the script. Right-click the `start_mihomo.ps1` file and select "Run with PowerShell" to start the service.

第一步：生成配置文件

在浏览器中打开 ClashSockify 工具，粘贴您的 Clash 订阅内容。设置好认证信息和端口后，点击“生成配置”，下载得到 `socks.yaml` 文件。

第二步：配置启动脚本

将下载的 `socks.yaml` 文件，与 `mihomo.exe` 核心程序放在同一个文件夹内（例如 D:\Mihomo\）。使用文本编辑器打开 `start_mihomo.ps1` 脚本，修改开头的路径配置。

请确保以下路径与您的实际文件位置完全一致： 

# --- 用户配置区域 ---

# 1. Mihomo 核心程序的完整路径
$MihomoPath = "D:\Mihomo\mihomo.exe"

# 2. ClashSockify 生成的配置文件的完整路径
$ConfigFile = "D:\Mihomo\socks.yaml"

# 3. 日志文件的存放目录 (程序会自动创建)
$LogDir     = "D:\Mihomo\logs"

# --- 配置结束 ---

第三步：运行

保存脚本。右键点击 `start_mihomo.ps1` 文件，选择“使用 PowerShell 运行”即可。
