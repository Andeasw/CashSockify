## English

ClashSockify is a simple yet powerful offline tool designed to transform a standard Clash configuration file into a multi-port SOCKS5 proxy server setup. It takes your entire list of proxies and exposes each one on a dedicated, sequential port, all secured by a single username and password.

This project is perfect for users who need to use individual proxies from their Clash subscription in applications that only support authenticated SOCKS5, or for sharing specific nodes without distributing the entire subscription file.

### ✨ Key Features

*   **Multi-Port SOCKS5 Conversion**: Instantly converts your entire list of Clash proxies into individual SOCKS5 proxies.
*   **Unified Authentication**: Secures every generated proxy port with a single, easy-to-manage username and password.
*   **Fully Offline & Secure**: The conversion tool (`index.html`) runs entirely in your browser. Your configuration is never uploaded, ensuring 100% privacy.
*   **Easy to Use**: A simple PowerShell script handles the backend service, making it easy to start, stop, and manage.

### 🚀 Getting Started (for Windows)

Follow these steps to get your SOCKS5 proxy service running.

#### Step 1: Prerequisites

1.  Download the latest release from the [Releases](https://github.com/Andeasw/ClashSockify/releases) page of this repository.
2.  Download the `mihomo` core for Windows from the [mihomo repository](https://github.com/MetaCubeX/mihomo/releases).
3.  Create a folder for this project (e.g., `D:\ClashSockify`) and place the `mihomo.exe` file inside it.

#### Step 2: Generate `socks.yaml`

1.  Open the `index.html` file (the ClashSockify tool) in your web browser.
2.  Paste the content of your Clash subscription/configuration file into the input text area.
3.  Set your desired **Username**, **Password**, and **Starting Port**.
4.  Click the "Generate Config" button and download the resulting **`socks.yaml`** file.
5.  Move the downloaded `socks.yaml` into the same folder you created in Step 1 (e.g., `D:\ClashSockify`).

#### Step 3: Configure the Startup Script

1.  Open the `start_mihomo.ps1` script with a text editor (like Notepad or VS Code).
2.  Modify the paths at the top of the file to match the actual location of your files.

    ```powershell
    # --- User Configuration Area ---

    # 1. Full path to the Mihomo core executable
    $MihomoPath = "D:\ClashSockify\mihomo.exe"

    # 2. Full path to the configuration file generated by ClashSockify
    $ConfigFile = "D:\ClashSockify\socks.yaml"

    # 3. Directory where log files will be stored (will be created automatically)
    $LogDir     = "D:\ClashSockify\logs"

    # --- End of Configuration ---
    ```

#### Step 4: Run the Service

*   Save the `start_mihomo.ps1` script.
*   Right-click on it and select **"Run with PowerShell"**.

Your SOCKS5 proxy service is now running in the background! Each proxy from your original config is now accessible on a sequential port, starting from the one you specified.

## 中文

ClashSockify 是一个简洁且强大的离线工具，旨在将标准的 Clash 配置文件转换为一个多端口的 SOCKS5 代理服务器配置。它会读取您配置文件中的所有代理节点，并将每一个节点映射到一个独立的、连续的本地端口上，所有端口均由一组统一的用户名和密码保护。

本项目非常适合那些需要在仅支持 SOCKS5 认证的应用中使用 Clash 节点的，或者希望在不泄露整个订阅文件的情况下分享特定节点的用户。

### ✨ 主要功能

*   **多端口 SOCKS5 转换**：一键将您 Clash 配置文件中的所有代理转换为独立的 SOCKS5 代理。
*   **统一认证**：使用一组您自定义的用户名和密码，保护所有生成的代理端口。
*   **完全离线与安全**：转换工具 (`index.html`) 完全在您的浏览器中本地运行，您的配置文件绝不会被上传，确保 100% 的隐私安全。
*   **简单易用**：通过一个简单的 PowerShell 脚本来管理后台服务，轻松启动、停止和管理。

### 🚀 快速上手 (适用于 Windows)

请遵循以下步骤来启动您的 SOCKS5 代理服务。

#### 第一步：准备文件

1.  从本项目的 [Releases](https://github.com/Andeasw/ClashSockify/releases) 页面下载最新的发行包。
2.  从 [mihomo 的官方仓库](https://github.com/MetaCubeX/mihomo/releases)下载适用于 Windows 的 `mihomo` 核心。
3.  为本项目创建一个文件夹（例如 `D:\ClashSockify`），并将下载的 `mihomo.exe` 放在其中。

#### 第二步：生成 `socks.yaml`

1.  在您的浏览器中打开 `index.html` 文件（即 ClashSockify 工具）。
2.  将您的 Clash 订阅或配置文件的内容粘贴到输入框中。
3.  设置您想要的**认证用户名**、**认证密码**和**起始端口**。
4.  点击“生成配置”按钮，下载生成的 **`socks.yaml`** 文件。
5.  将下载的 `socks.yaml` 文件移动到您在第一步创建的文件夹中（例如 `D:\ClashSockify`）。

#### 第三步：配置启动脚本

1.  使用文本编辑器（如记事本或 VS Code）打开 `start_mihomo.ps1` 脚本。
2.  修改文件头部的路径，确保它们与您的实际文件位置完全一致。

    ```powershell
    # --- 用户配置区域 ---

    # 1. Mihomo 核心程序的完整路径
    $MihomoPath = "D:\ClashSockify\mihomo.exe"

    # 2. ClashSockify 生成的配置文件的完整路径
    $ConfigFile = "D:\ClashSockify\socks.yaml"

    # 3. 日志文件的存放目录 (程序会自动创建)
    $LogDir     = "D:\ClashSockify\logs"

    # --- 配置结束 ---
    ```

#### 第四步：运行服务

*   保存 `start_mihomo.ps1` 脚本。
*   右键点击该文件，并选择 **“使用 PowerShell 运行”**。

现在，您的 SOCKS5 代理服务已在后台成功运行！您原始配置中的每一个代理节点，都可以通过从您设定的起始端口开始的连续端口进行访问。
