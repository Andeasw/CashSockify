**CashSockify** is a simple yet powerful offline tool designed to transform a standard Clash configuration file into a multi-port SOCKS5 proxy server setup. It takes your entire list of proxies and exposes each one on a dedicated, sequential port, all secured by a single username and password.

This project is perfect for users who need to use individual proxies from their Clash subscription in applications that only support authenticated SOCKS5, or for sharing specific nodes without distributing the entire subscription file.

### ✨ Key Features

*   **Multi-Port SOCKS5 Conversion**: Instantly converts your entire list of Clash proxies into individual SOCKS5 proxies.
*   **Unified Authentication**: Secures every generated proxy port with a single, easy-to-manage username and password.
*   **Fully Offline & Secure**: The conversion tool (`index.html`) runs entirely in your browser. Your configuration is never uploaded, ensuring 100% privacy.
*   **Easy to Use**: A set of PowerShell scripts handles the backend service, making it easy to start, stop, and manage.

### 🚀 Getting Started (for Windows)

Follow these steps to get your SOCKS5 proxy service running.

#### Step 1: Prerequisites

1.  Download the latest release from the [Releases](https://github.com/Andeasw/CashSockify/releases) page of this repository.
2.  Download the `mihomo` core for Windows from the [mihomo repository](https://github.com/MetaCubeX/mihomo/releases).
3.  Create a folder for this project (e.g., `D:\CashSockify`) and place the `mihomo.exe` file inside it.

#### Step 2: Generate `socks.yaml`

1.  Open the `index.html` file (the CashSockify tool) in your web browser.
2.  Paste the content of your Clash subscription/configuration file into the input text area.
3.  Set your desired **Username**, **Password**, and **Starting Port**.
4.  Click the "Generate Config" button and download the resulting **`socks.yaml`** file.
5.  Move the downloaded `socks.yaml` into the same folder you created in Step 1 (e.g., `D:\CashSockify`).

#### Step 3: Configure the Startup Scripts

> **Important**: Before proceeding, open **all three `.ps1` scripts** (`start_mihomo.ps1`, `Start-Process.ps1`, and `stop-mihomo.ps1`) with a text editor and ensure the path variables at the top are correctly set to your actual file locations.

Modify the paths at the top of each script file:
```powershell
# --- User Configuration Area ---

# 1. Full path to the Mihomo core executable
$MihomoPath = "D:\CashSockify\mihomo.exe"

# 2. Full path to the configuration file generated by CashSockify
$ConfigFile = "D:\CashSockify\socks.yaml"

# 3. Directory where log files will be stored (will be created automatically)
$LogDir     = "D:\CashSockify\logs"

# --- End of Configuration ---
```

#### Step 4: Run the Service

This project includes several scripts to manage the service. Ensure paths are correctly set in all of them before running.

*   `start_mihomo.ps1`: Runs the service in the **background**. This is the recommended way for daily use. The PowerShell window will close, but the process continues running.
*   `Start-Process.ps1`: Runs the service in the **foreground**. This is useful for debugging as you can see the log output directly in the terminal.
*   `stop-mihomo.ps1`: **Stops** the background service started by `start_mihomo.ps1`.

To start, right-click on `start_mihomo.ps1` and select **"Run with PowerShell"**.

### 🔧 Troubleshooting

1.  **Errors during generation or proxy not working?**
    The most common cause of issues is an incorrectly formatted YAML file pasted into the conversion tool. Please double-check your source configuration for any syntax errors, extra spaces, or incorrect indentation. The tool expects a standard Clash `proxies` list.

2.  **Garbled text (Mojibake) in the console?**
    When using `Start-Process.ps1` for foreground debugging, you might see garbled text. This is a common display issue with older versions of Windows PowerShell. **This does not affect the proxy's functionality.** You can fix the display by upgrading to a modern version of [PowerShell (7+)](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows), but it is not required for the service to work.
