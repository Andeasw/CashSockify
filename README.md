# CashSockify

![License](https://img.shields.io/badge/license-MIT-green.svg)![Language](https://img.shields.io/badge/language-HTML%20%26%20JS-orange.svg)![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)

---

**CashSockify** is a simple yet powerful offline tool designed to transform a standard Clash configuration file into a multi-port Local Socket Secure proxy server setup. It takes your entire list of proxies and exposes each one on a dedicated, sequential port, all secured by a single username and password.

This project is perfect for users who need to use individual proxies from their Clash subscription in applications that only support authenticated Socket Secure, or for sharing specific nodes without distributing the entire subscription file.

### ✨ Key Features

*   **Multi-Port Socket Secure Conversion**: Instantly converts your entire list of Clash proxies into individual Socket Secure proxies.
*   **Unified Authentication**: Secures every generated proxy port with a single, easy-to-manage username and password.
*   **Fully Offline & Secure**: The conversion tool (`index.html`) runs entirely in your browser. Your configuration is never uploaded, ensuring 100% privacy.
*   **Zero Configuration**: No need to edit script files. The scripts automatically find the core and configuration file in the same directory.
*   **Easy to Use**: A set of PowerShell scripts handles the backend service, making it easy to start, stop, and manage.

### 🚀 Getting Started (Windows)

The usage has been greatly simplified. Just follow three steps to get your Socket Secure proxy service running.

#### Step 1: Prepare the Files

1.  **Download Project Files**: Download all files from this GitHub repository (e.g., via `Download ZIP`) and place them into a new, single folder (e.g., `D:\CashSockify`).
2.  **Download Mihomo Core**: Download the latest `mihomo` core for Windows from the [mihomo repository](https://github.com/MetaCubeX/mihomo/releases).
3.  **Rename & Place Core**: Rename the downloaded executable to `mihomo-windows-amd64-v1.exe` and place it in the same folder you created above.

Your folder should now contain the project files and the renamed mihomo core.

#### Step 2: Generate `socks.yaml`

1.  **Open the Tool**: Open the `index.html` file in your web browser.
2.  **Paste Your Config**: Paste the content of your Clash subscription/configuration file into the input text area.
3.  **Set Credentials**: Set your desired **Username**, **Password**, and **Starting Port**.
4.  **Generate & Download**: Click the "Generate Config" button and download the resulting **`socks.yaml`** file.
5.  **Place Config File**: Move the downloaded `socks.yaml` into the same folder as all the other files.

At this point, your folder should contain the project files, `mihomo-windows-amd64-v1.exe`, and `socks.yaml`.

#### Step 3: Run the Service

With all required files in the same directory, simply right-click on `start_mihomo.ps1` and select **"Run with PowerShell"**.

The script will start the service in the background, and the PowerShell window will close automatically. Your Socket Secure proxies are now running.

*   **To Stop the Service**: Right-click `stop_mihomo.ps1` and select "Run with PowerShell".
*   **For Debugging**: If you need to see live output, run `Start-Process.ps1`. This will keep the console window open to display logs.

### 📁 Directory Structure

For the scripts to work without any modification, all the following essential files must be placed in a single folder.

```
/Your-Folder/
│
├── index.html                   # The main conversion tool you open in a browser.
├── Instructions.html            # A detailed quick-start guide.
├── jquery.min.js                # Required JavaScript library for the tool.
├── js-yaml.min.js               # Required JavaScript library for YAML processing.
│
├── mihomo-windows-amd64-v1.exe  # The mihomo core (must be downloaded and renamed).
├── socks.yaml                   # The configuration file generated by index.html.
│
├── start_mihomo.ps1             # Main script to run the service in the background.
├── Start-Process.ps1            # Script to run the service for debugging.
├── stop_mihomo.ps1              # Script to stop the running service.
│
└── /logs/                       # This folder is created automatically to store logs.
```

### 🔧 Troubleshooting

1.  **Errors during generation or proxy not working?**
    The most common cause of issues is an incorrectly formatted YAML file pasted into the conversion tool. Please double-check your source configuration for any syntax errors, extra spaces, or incorrect indentation. The tool expects a standard Clash `proxies` list.

2.  **Garbled text (Mojibake) in the console?**
    When using `Start-Process.ps1` for debugging, you might see garbled text. This is a common display issue with older versions of Windows PowerShell and **does not affect the proxy's functionality.** You can fix this by upgrading to a modern version of [PowerShell (7+)](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows), but it is not required for the service to work.
